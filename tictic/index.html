Set up in three minutes

Download. Allow. Start talking.

TicTic is an early Mac beta, so the first opening has one extra security step. After that, it lives quietly in your menu bar.

Step one

Move TicTic to Applications

Download the ZIP, open it, then drag TicTic.app into your Applications folder.

Step two

Open the beta safely

In Applications, Control-click TicTic and choose Open. Confirm Open once more. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway.

Step three

Connect and grant access

Add your own Sarvam API key, then allow Microphone and Accessibility when TicTic asks.

Why Accessibility? It lets TicTic hear the global shortcut and insert completed text at your cursor. It does not give TicTic your passwords or send the contents of other apps anywhere.

Privacy, plainly

Your Mac does the work. Your key pays for it.

There is no TicTic account, analytics service, application server, or database. Your Mac talks directly to Sarvam using the API key you provide.

Audio is temporaryRecordings are sent directly to Sarvam for transcription and deleted from your Mac after each request.
Your key stays in KeychainYour Sarvam API key is stored in macOS Keychain and used only for requests from the app.
History stays localText history is saved only on your Mac. You can disable it or clear it at any time in Settings.
Good to know

Before you download.

Which Macs are supported?

This beta supports Apple silicon Macs—M1, M2, M3, M4 and newer—running macOS 14 or later. An Intel build is not included yet.

Why does macOS warn me when I open it?

This friend beta is not yet notarized by Apple. Control-click the app, choose Open, and confirm. Only download TicTic from this page or the linked GitHub repository.

Do I need a Sarvam account?

Yes. TicTic currently uses your personal Sarvam API key, so requests, quotas, and any usage charges belong to your Sarvam account.

Does TicTic run in the cloud?

The app runs on your Mac. Only recorded audio and optional formatting requests go directly to Sarvam. Nandana does not operate a proxy server for TicTic.

How do updates work?

Updates are manual during the beta. Return to this page, download the latest ZIP, quit TicTic, and replace the old app in Applications.
