Mycelium

Agent runtime · v1.13.4 · 7.4k+ PyPI downloads · Open source

Runtime guards and zero-touch YAML auto-instrumentation for AI agents on LangGraph, CrewAI, and custom loops. Stops duplicate side effects on retry/redispatch, blocks bad tool args and out-of-scope calls, and keeps tool data fresh — before execution, not after.

Read docs · View source · Install from PyPI · Download stats

Read architecture / key engineering decisions
Agent loop → Mycelium guards → Tool execution

Mycelium sits between the agent loop and tools. mycelium init / mycelium run wrap configured callables from YAML — no decorators required. It classifies side effects, issues durable transition envelopes (lease + terminal state + hard-block / reconcile), and fail-closes ambiguous mutating retries instead of blind re-execute.
