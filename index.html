Mycelium

Agent reliability runtime · v1.31.0 · {{MYCELIUM_DOWNLOADS}} PyPI downloads · Open source

A framework-independent Python runtime for consequential agent tool calls. Durable transition envelopes make retries, crashes, and concurrent redispatches return stored results, poll in-flight work, reconcile provider state, or fail closed instead of blindly repeating a mutation.

Read the architecture · Read docs · View source · Install from PyPI · Download stats

Read architecture / key engineering decisions
Agent loop → Mycelium guards → Tool execution

Mycelium sits between the agent loop and tools. mycelium init / mycelium run wrap configured callables from YAML, while decorators and manual claim/execute/complete flows remain available. File, SQLite, Redis, and PostgreSQL ledgers persist leases, side-effect boundaries, and terminal outcomes. The repository's 800+ test verification posture covers process crashes, multi-worker races, storage outages, reconciliation, and operator release. It does not claim to solve hallucination, prompt injection, or general goal alignment.
